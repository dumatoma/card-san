## 2026-10-12 管理ウェブサイト(jppc/jp-card-pc)

**本番反映:** 2026-10-12 01:28(日本時間)、`/www/wwwroot/card-san.jp` に手動配置(`js/app.5bedc5f2.js`)
**配置前のバックアップ:** `/www/backup_jppc_20261012_000639.tgz`
**配置前の確認:** 本番のビルドに含まれるソース78ファイルが、GitHub の `bf1c000` と一致していることを確認済み

### 1. ログイン画面のブロックがTOPバーに重なる

| 項目 | 内容 |
|------|------|
| 症状 | ウィンドウの高さが低いと、ログインのブロックがTOPバーの上に重なり、下側もフッターに隠れる |
| 原因 | ブロックを「画面の高さの40%」を基準に配置していたため、高さによって位置が変わっていた |
| 修正 | ブロックをTOPバーの40px下に固定。画面が低いときはページをスクロールしてフッターを表示する |
| ファイル | `src/views/login/login.vue`(スタイルのみ) |

### 2. 認証コード・電話番号・副管理者ログイン画面の同じ重なり

| 項目 | 内容 |
|------|------|
| 症状 | 1と同じ。認証コード画面と電話番号ログイン画面では、フッターがボタンや説明文を隠していた |
| 修正 | 1と同じ配置に統一。ポップアップの背景は画面全体を覆うよう固定表示に変更 |
| ファイル | `src/views/login/codeLogin.vue`、`phoneLogin.vue`、`deputyAdmin.vue`(スタイルのみ) |

### 3. 新規予約でメニューを選ぶと当日担当が先頭のスタッフに変わる(再発の修正)

| 項目 | 内容 |
|------|------|
| 症状 | 新規予約でメニューを選ぶと、当日担当の名前と色がスタッフ一覧の先頭の人に変わる |
| 経緯 | 2026-06-05 に開発会社がサーバー上のビルド済みファイルを直接修正(`BUG_FIX_LOG.md` #28)。ソースに反映されていなかったため、2026-10-01 の再ビルドで修正が消え、不具合が再発していた |
| 修正 | 選択中の当日担当(列から開いたスタッフ、または手動で選び直したスタッフ)を維持する。メニューを担当できないスタッフの場合のみ先頭のスタッフにする |
| ファイル | `src/views/appointment.vue`(`sceenStaff()`、`selThis()`) |

- 修正のたびに、このファイルに追記する
