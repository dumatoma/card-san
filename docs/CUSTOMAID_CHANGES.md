## 2026-10-12(9回目) チャット送信時のプッシュ通知の順番(サーバー側)

**注意: サーバー(api.card-san.jp)のPHPはGitHubで管理されていないため、変更内容をここに記録する。**

### 18. Card-San App から送ったメッセージの表示が遅い

| 項目 | 内容 |
|------|------|
| 症状 | Card-San App(お客様)からお店にメッセージを送ると、自分のメッセージが画面に出るまで時間がかかる(以前から) |
| 原因 | アプリは、サーバーからチャット通知(wss)が戻ってきてから表示する作り。サーバーの送信処理が、管理者全員へのプッシュ通知(個推 GeTui・中国のサーバー)の返事を待ってから、メッセージの保存とチャット通知をしていた |
| 副次的な不具合 | (1) 個推がエラーのときは、メッセージ自体が保存されなかった (2) 未読数を+1する前にバッジ数を数えていたため、管理アプリのバッジが1件少なく出ていた |
| 修正 | 個推への送信を、保存の確定(`DB::commit()`)のあとに移動。個推がエラーでもメッセージは送信成功のまま(エラーは `storage/logs/getui/` に記録) |
| ファイル | `/www/wwwroot/api.card-san.jp/app/Http/Controllers/Api/Member/MessageController.php`(`store`) |

### 19. 管理App・管理WEBから送ったメッセージが、個推のエラー時に消える

| 項目 | 内容 |
|------|------|
| 症状 | 表示の遅れはない(チャット通知が先)。ただし、個推がエラーのときは、画面に表示済みのメッセージが保存されずに消えていた |
| 修正 | 18と同じく、個推への送信を `DB::commit()` のあとに移動し、エラーでも送信成功のままにした |
| ファイル | `/www/wwwroot/api.card-san.jp/app/Http/Controllers/Api/Shop/MessageController.php`(`store`) |

**18・19 共通**

- 変更日時: 2026-10-12 19:02(日本時間)
