# Google Business Profile 連携設定ガイド

Card-San の「Googleクチコミ管理」「GBP投稿」機能を利用するには、Google Cloud Console でプロジェクトを作成し、認証情報を取得する必要があります。

所要時間：約 20〜30 分

---

## 事前準備

- Google アカウント（Google Business Profile に登録済みのもの）
- Google Business Profile（GBP）にお店が登録されていること

> GBP にまだお店を登録していない場合は、[https://business.google.com](https://business.google.com) から先にお店の登録を完了してください。

---

## Step 1 ｜ Google Cloud Console にアクセス

1. ブラウザで [https://console.cloud.google.com](https://console.cloud.google.com) を開きます
2. GBP に登録したのと**同じ Google アカウント**でログインします
3. 利用規約が表示された場合は「同意して続行」をクリックします

---

## Step 2 ｜ プロジェクトを新規作成

1. 画面上部の「**プロジェクトを選択**」をクリックします
2. 右上の「**新しいプロジェクト**」をクリックします
3. 以下を入力して「**作成**」をクリックします

   | 項目 | 入力例 |
   |------|--------|
   | プロジェクト名 | `MyShop-CardSan` など任意の名前 |
   | 場所 | 変更不要（「組織なし」のまま） |

4. 作成後、画面上部の「プロジェクトを選択」から今作成したプロジェクトを選択します

---

## Step 3 ｜ 必要な API を有効化

### 3-1. API ライブラリを開く

左側メニュー → 「**APIとサービス**」→「**ライブラリ**」をクリックします

### 3-2. 以下の API を順番に有効化します

それぞれ検索ボックスに名前を入力 → 検索結果をクリック → 「**有効にする**」ボタンをクリックしてください。

| API 名 | 用途 |
|--------|------|
| **My Business Account Management API** | GBP アカウント情報の取得 |
| **My Business Business Information API** | 店舗情報・ロケーションの取得 |
| **My Business Reviews API** | クチコミの取得・返信・削除 |
| **My Business Lodging API** | 施設情報（一部業種で必要） |
| **Places API** | 地図情報の補助 |

> **注意：** 「Business Profile Performance API」など似た名前のものと間違えないようにご注意ください。

---

## Step 4 ｜ OAuth 同意画面を設定

1. 左メニュー → 「**APIとサービス**」→「**OAuth 同意画面**」をクリックします
2. ユーザーの種類で「**外部**」を選択し「**作成**」をクリックします
3. 以下を入力します

   | 項目 | 入力内容 |
   |------|----------|
   | アプリ名 | お店の名前や任意の名前（例：`山田美容室 Card-San`） |
   | ユーザーサポートメール | ご自身のメールアドレス |
   | デベロッパーの連絡先メール | ご自身のメールアドレス |

4. 「**保存して次へ**」をクリックします（スコープの追加画面は何も変更せず「保存して次へ」）
5. テストユーザーの追加画面で「**+ ADD USERS**」をクリックし、ご自身の Google アカウントのメールアドレスを追加します
6. 「**保存して次へ**」→「**ダッシュボードに戻る**」をクリックします

> **ポイント：** 公開設定は「テスト」のままで構いません。Card-San のサポートがアプリ確認済みへの変更を対応します。

---

## Step 5 ｜ OAuth 2.0 クライアント ID を作成

1. 左メニュー → 「**APIとサービス**」→「**認証情報**」をクリックします
2. 上部の「**+ 認証情報を作成**」→「**OAuth クライアント ID**」をクリックします
3. 「アプリケーションの種類」で「**ウェブ アプリケーション**」を選択します
4. 名前は任意（例：`Card-San Web Client`）で構いません
5. 「**承認済みのリダイレクト URI**」の「+ URIを追加」をクリックし、以下を正確に入力します

   ```
   https://api.card-san.jp/api/shop/google_business/callback/mobile
   ```

6. 「**作成**」をクリックします

---

## Step 6 ｜ 認証情報を控える

作成が完了すると「OAuth クライアントを作成しました」というポップアップが表示されます。

以下の 2 つをメモしてください（後ほど Card-San サポートにお知らせいただきます）：

| 項目 | 説明 |
|------|------|
| **クライアント ID** | `〇〇〇.apps.googleusercontent.com` の形式 |
| **クライアント シークレット** | ランダムな文字列 |

> ポップアップを閉じた後でも、「認証情報」ページ → 作成した OAuth クライアント名をクリックすると再度確認できます。

---

## Step 7 ｜ Card-San サポートに連絡

以下の情報を Card-San サポートまでお送りください。

```
【GBP 連携設定依頼】

■ クライアント ID：
（例：123456789-abcdefg.apps.googleusercontent.com）

■ クライアント シークレット：
（例：GOCSPX-xxxxxxxxxxxxxxxxxx）

■ GBP に登録しているメールアドレス：

■ 店舗名：
```

サポートが設定を完了次第、Card-San 管理アプリの「設定」→「Google Business設定」から連携操作が行えるようになります。

## よくある質問

**Q. 「このアプリは Google で確認されていません」と表示される**  
A. 「詳細」→「〇〇（安全ではないページ）に移動」をクリックして進んでください。テスト段階では表示される警告です。正式公開後は表示されなくなります。

**Q. API を有効化したのにエラーになる**  
A. 有効化直後は反映まで数分かかる場合があります。5分ほど待ってから再度お試しください。

**Q. 複数店舗を GBP に登録している**  
A. 現在は連携時に最初のアカウント・ロケーションが自動取得されます。複数店舗の対応についてはサポートまでご相談ください。

**Q. クライアントシークレットを紛失した**  
A. 「認証情報」ページ → 対象の OAuth クライアント → 「シークレットを再生成」から新しいシークレットを発行できます。再発行後はサポートまでご連絡ください。
