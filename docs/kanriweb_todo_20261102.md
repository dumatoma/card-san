## 4. サーバーとの関係のまとめ

**サーバーはもう直してあるので、画面だけ作ればよいもの**

- 予約通知の「確認済み(名前)」・連絡のしかたのマーク・予約詳細のメールアドレス
- お休み/休憩・勤務時間外の名前の保存
- 予約表の時間(7:00〜24:00)
- 一斉配信・クーポンの新しい絞り込み、一斉配信の写真4枚
- クーポンの POS バーコード
- お知らせの投稿した日・編集した日、Instagram の投稿の一覧
- カードの枠の画像
- 副管理者の権限「カルテ」

**サーバーも直す必要があるもの(または、まだ分からないもの)**

- 一部の週だけ休みを自動で入れる処理:今は 管理App を開いたときに App が入れている。WEB だけ使うお店のために、WEB でも入れるか、サーバーで入れるか決める(確認が必要)
- 下の「5. まだ作っていない予定のもの」はすべて、サーバーの直しも要る

## 6. おすすめの順番

1. **予約表の時間(7:00〜24:00)とお休みの2つ分け**:App と WEB で予約の見え方がちがうと、二重予約などのまちがいにつながるため。サーバーは済み
2. **予約通知の小さな直し**:確認済み(名前)・連絡のしかたのマーク・メールアドレス・取り消しの文・日付の太字。サーバーは済みで、すぐできる
3. **お知らせの日付・副管理者の「カルテ」権限・サンキューの説明・スタンプ満了の文**:小さいものをまとめて
4. **絞り込みの直し(一斉配信・クーポン)**:今のままだと届く人がずれる
5. **クーポンのコピー・POS バーコード、一斉配信の写真4枚**
6. **一部の週だけ休み**(自動で入れる場所を決めてから)
7. **段階7(予約受付用メールアドレス・BCC・お店の予約のメール欄・外部の予約)**:App と WEB を同じときに作る
8. **無料期間の帯と全面のお知らせ**:サーバーの今の動きを調べてから(決定事項の「このあとの順番」のとおり)
9. カードの枠の画像・色えらび・Instagram の一覧(急がない)
