## メールの種類と、いつ送るか
| kind | 中身 | いつ |
|---|---|---|
| 3 | 無料期間 残り7日 | 最初の30日の終わりの7日前〜6日前 |
| 4a / 4b | 前日(延長あり/なし) | 最初の30日の終わりの前日(会員30人以下/31人以上) |
| 5 | 延長の終わる前日 | 延長中・31人を超えていない・終わりの前日 |
| 5o(5') | 会員が30人を超えた | 延長中に31人を超えた印が付いたとき(1回) |
| 5s(5'') | お客様のアプリが止まる前日 | 無料期間が終わって延長されないお店・猶予の最終日の前日 |
| 6 | ご契約ありがとうございます | 新しい有料の契約が始まったとき(前の契約と2日以上あいている) |
| 8 | ご契約内容を変更しました | プラン・周期・払い方が前の記録とちがう記録が始まったとき |
| 7 | 解約を受け付けました | 有料の契約中に解約の印が付いたとき |
| 7a | 明日でご契約が終了 | 解約した契約の終わりの前日 |
| 7b | ご契約が終了しました | 有料の契約が終わって6時間〜3日(解約/お支払いが確認できない) |
- テスト用店舗(1・4・7)には、無料期間のメールは送らない(契約のメールは送る)
- App内課金→カード払いの予約中(status 0 の Stripe)は、無料期間・解約のメールを送らない
- 送り先は持ち主(web_shop_admin admin_type=1)のメールアドレス

## 本当に送る設定
.env に `CS_SHOP_NOTICE_SEND=true` を書くまでは、毎時の処理は一覧を出すだけ(送らない・記録しない)。

## 手順
1. 10回に分けて貼る → md5 → 展開(/root/cs_notice/)
2. `php -d disable_functions= notice_patch.php`(確認だけ)→ `apply`
3. `php -d disable_functions= artisan cs:shop-notice --dry`(一覧)
4. `php -d disable_functions= artisan cs:shop-notice --sample --to=坂本さんのアドレス`(見本11通)
5. 坂本さんの OK のあと .env に CS_SHOP_NOTICE_SEND=true
戻すとき:`notice_patch.php undo`
