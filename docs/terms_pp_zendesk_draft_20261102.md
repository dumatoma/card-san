# A. サービス利用規約(店舗向け) 全文の案

サービス利用規約

合同会社カスタムエイド(以下「甲」といいます。)は、メンバーズカードアプリ作成サービス「Card-San」(以下「本サービス」といいます。)を利用者(以下「乙」といいます。)に提供するにあたり、本利用規約を次のとおり定めます。

第1条(定義)
本利用規約で使う言葉の意味は、次のとおりとします。
1. 「利用者」:甲が定める手続きに従い、本サービスの全部または一部を利用する資格を得た法人、団体または個人
2. 「管理アプリ」「管理WEB」:乙が本サービスを設定・運用するための、スマートフォンアプリ「CardSan管理」およびウェブサイト
3. 「お客様用アプリ」:乙のお客様が使うスマートフォンアプリ「Card-San」のうち、乙のお店のページ・会員証・予約などの機能
4. 「会員」:お客様用アプリで乙のお店の会員になったお客様
5. 「無料お試し期間」:第3条に定める、料金がかからずに本サービスを利用できる期間
6. 「本契約」:第4条により成立する、本サービスの有料の利用契約

第2条(規約の適用)
1. 本利用規約は、乙が本サービスの全部または一部を利用する場合に適用され、乙は本サービスを利用することにより、本利用規約に同意したものとします。
2. 甲は、乙の承諾を得ることなく本利用規約を変更することができます。その場合、甲は、本サービスのウェブサイトへの掲示、電子メールその他甲が適切と判断する方法で、乙に知らせます。
3. 甲がオンラインその他の方法で示すプライバシーポリシー、マニュアル、ガイドライン等(以下「諸規定」といいます。)は、本利用規約の一部を構成します。

第3条(無料お試し期間)
1. 乙は、アカウントを登録した日から30日間、本サービスのすべての機能を無料で利用できます。
2. 30日が過ぎた時点で会員が30人以下の場合、無料お試し期間は、アカウント登録日から最大60日目まで自動で延長されます。
3. 延長中に会員が31人になった場合、無料お試し期間は、31人目の会員が登録された時点から24時間後に終了します。アカウント登録日から60日目を過ぎた場合は、会員の人数にかかわらず終了します。
4. 会員を削除して30人以下に戻した場合でも、終了した無料お試し期間は元に戻りません。
5. 無料お試し期間が終了しても、自動で料金が請求されることはありません。
6. 無料お試し期間が終了したあと、本契約のお申し込みがあるまでの間、乙は、管理アプリ・管理WEBで、本契約のお申し込み、契約内容の確認、お問い合わせおよびログアウトのみ行うことができます。お客様用アプリは、無料お試し期間が終了した日から3日間は利用でき、その後は利用できなくなります。
7. 無料お試し期間が終了し、本契約のお申し込みがない場合のデータの取り扱いは、第11条第3項から第5項に準じます(終了から30日後に削除)。
8. 甲は、無料お試し期間が終了する前に、電子メールおよび管理アプリ・管理WEBの表示で乙に知らせます。

第4条(本契約の成立)
1. 乙は、甲が定める方法(管理WEBでのクレジットカード決済、管理アプリでのApp内課金(App Store)またはGoogle Play課金)により、本契約を申し込みます。
2. 決済が完了した日を本契約開始日とし、本契約が開始します。無料お試し期間中にお申し込みいただいた場合も、お申し込みの日から本契約が開始し、利用料金の請求が始まります。この場合、残りの無料お試し期間はなくなります。
3. 1年契約は、管理WEBからのお申し込みに限ります。

第5条(利用料金)
1. 利用料金は、甲が別途定める料金表(管理アプリ・管理WEB・ヘルプセンターに掲載)によります。
2. 甲は、乙の承諾を得ることなく、利用料金を変更することができます。その場合、甲は事前に乙に知らせ、変更後の利用料金は、変更の効力が生じた日以降の最初の契約更新日から適用します。
3. 乙が支払った利用料金は、理由のいかんを問わず、甲から返金しません。ただし、App Store・Google Playの規定による返金および調整、ならびにプラン変更時に決済サービス(Stripe・Apple・Google)が行う日割りの差し引き・調整は、この限りではありません。

第6条(利用料金の支払い)
1. 利用料金は、乙が本契約を申し込んだ方法(クレジットカード決済、App内課金またはGoogle Play課金)で支払うものとします。請求および領収書の発行は、各決済サービスが行います。
2. 【確認中】クレジットカード決済とApp内課金・Google Play課金の間で支払い方法を変える場合は、今の本契約が終了したあと、新しい支払い方法で改めて申し込むものとします。
3. 乙は、支払い方法に不備があった場合、直ちに甲に連絡するものとします。
4. 乙の過失により甲が支払いを確認できない場合、乙または第三者に生じた損害について、甲は責任を負いません。

第7条(利用期間と自動更新)
1. 本契約の利用期間は、乙が選んだお支払い周期(1ヶ月、6ヶ月または12ヶ月)とし、本契約開始日を起算日とします。例えば1月1日に1ヶ月で契約した場合、次回の請求は2月1日となります。31日など翌月に同じ日がない場合は、その月の末日の請求となります。
2. 本契約は、乙が解約の手続きをしない限り、同じ内容で自動更新されます。乙は、甲または各決済サービスが、次の利用期間の利用料金を乙の支払い方法に請求することを承諾します。

第8条(プランとお支払い周期の変更)
1. アップグレード(上位のプランへの変更)は、手続きをした日から新しいプランが適用されます。今のプランの残りの期間の扱い(日割りの差額の請求・差し引き・返金)と次回の請求日は、支払い方法ごとに各決済サービスの規定によります。
2. ダウングレード(下位のプランへの変更)およびお支払い周期だけの変更は、今の利用期間の終了日の翌日(契約更新日)から適用されます。それまでは今の内容で利用できます。
3. 詳しくは、ヘルプセンターの「利用プランを変更した場合の料金」に定めます。
4. オプション料金は、1ヶ月ごとの契約とします。複数月の契約をした場合も、オプション料金は起算日ごとに別に請求されます。

第9条(解約)
1. 乙は、今の利用期間の終了日の前日までに解約の手続きをすることで、本契約を解約できます。オプションのみの解約も同様とします。

4. 乙は、今の利用期間の終了日までであれば、解約を取り消して本契約を続けることができます(クレジットカード決済は管理WEBの「継続する」、App内課金・Google Play課金は定期購入の再開)。

第10条(支払いができない場合)
契約更新時に利用料金の支払いが確認できない場合、各決済サービスによる再請求ののち、なお支払いが確認できないときは、本契約は終了します。

## D-9. 新しい記事:無料お試し期間について(セクション「ご利用プラン」)

Card-San は、アカウントを登録した日から **30日間**、すべての機能を無料でお試しいただけます。

**無料お試し期間の決まり**
- 30日がたった時点で、お店の会員が **30人以下** なら、無料お試し期間が **登録から最大60日目** まで自動で延びます。お手続きはいりません。
- 延びている間に会員が **31人** になると、31人目が登録された時点から **24時間後** に無料お試し期間が終わります。
- 登録から60日目を過ぎると、会員の人数にかかわらず終わります。
- 会員を削除して30人以下に戻しても、無料お試し期間は元に戻りません。
- 無料お試し期間が終わっても、自動でお金がかかることはありません。

**終わる前のお知らせ**
終わる7日前・前日などに、メールでお知らせします。会員が31人になったときは、すぐにメールと管理アプリ・管理WEBの表示でお知らせします。

**終わったあと**
- 管理アプリ・管理WEBは、お申し込み・契約内容の確認・お問い合わせ・ログアウトだけできる状態になります。
- お客様のアプリは、終わった日から **3日間** は使えます。そのあとは使えなくなります。
- お申し込みいただくと、すぐに今までどおりお使いいただけます。
- 無料お試し期間中にお申し込みいただくと、その日から有料のご契約が始まり、料金の請求が始まります(残りの無料お試し期間はなくなります)。
